# Secure Authentication System  
Multi-factor authentication system using Password + TOTP + JWT.

## 🔐 Project Description
This project implements a secure authentication system with:
- Password hashing (bcrypt)
- TOTP (Google Authenticator)
- JWT access + refresh tokens
- Session management
- User registration & login flows

Created for the SDU Cryptography Course (Option 3).

## ✨ Features
- Secure password hashing using bcrypt
- TOTP-based MFA (Google Authenticator)
- JWT access/refresh tokens with expiration
- Input validation & error handling
- Threat model + mitigation
- Unit tests
